# Mavue 利用条件の論点（法務確認用）

> 利用条件の本文（日英）は `licenses/EULA.txt`。リリース候補（RC）では**法務確認前の草案**として配布物の `licenses\EULA.txt` に同梱している
> （冒頭に草案である旨、確定前の箇所に【要法務確認】/[LEGAL REVIEW]）。本書はその背景と、法務確認で決めるべき論点の作業文書（配布物には含めない）。

## 0. なぜ必要か（背景）

- Mavue 自身のソースコードは Apache License 2.0（`LICENSE`）。Apache-2.0 は Mavue のコードの利用・再配布を許可するが、
  **バイナリ配布に同梱する Microsoft のコード**（Windows App SDK、Windows SDK の C# 投影など）の再配布条件は別にある。
- Windows App SDK（`license.txt` §3(b)）と Windows SDK（Distribution Requirements）は、再配布する者に次を求める（`docs/DEPENDENCIES.md` §0）:
  主要な機能を加えること、**配布者とエンドユーザーに、Microsoft のコードを本契約と同等以上に保護する条項へ同意させること**、
  自分の著作権表示を表示すること、Microsoft を補償すること、Microsoft の商標を誤認させる形で使わないこと。
- そのため、バイナリ（ZIP・MSIX）の利用者向けに、第三者コンポーネントの条件を受け継ぐ利用条件が必要になる。
- 注意: 本条件で Mavue のソースコードに対する Apache-2.0 の権利を狭めてはならない（Apache-2.0 で受け取った者の権利は Apache-2.0 が定める）。【要法務確認: 両者の書き分け】

## 2. 配布物への反映

- 済（RC）: `licenses/EULA.txt`（日英）を配布物の `licenses\EULA.txt` に同梱し、`tools/build-release.ps1` の整合チェックの必須ファイルに追加。
  Install.cmd の完了表示と ZIP の README.txt で場所を案内。アプリの 設定 › Mavue について › ライセンス情報 で開くフォルダーにある。
- 法務確認後: 草案の表記と【要法務確認】を外して確定版にする。以下は同意の取り方が決まってから実装する。
- `Install.ps1` で利用条件を表示し、同意しなければ中止する（`-AcceptEula` のような無人インストール用スイッチを含め要設計）。
- MSIX: パッケージ自体には同意画面がないため、初回起動時の表示、または Store の「ライセンス条項」欄を使う。【要検討】
